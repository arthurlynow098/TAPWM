# TAPWM

## Sobre o projeto

Coleção de atividades de programação web com HTML, JavaScript e exemplos de servidor em Node.js, Express e EJS. As pastas registram exercícios separados, de páginas no navegador a portais com rotas e templates.

## Como explorar

- Abra os arquivos HTML das atividades iniciais no navegador.
- Nas atividades 18 e 19, entre na pasta correspondente e execute `npm install` e `npm start`. Os scripts usam nodemon e iniciam `app.js`.
- Consulte os READMEs internos das atividades 19 e 20 para orientações específicas.

Cada atividade tem seu próprio contexto. Os comandos não foram executados nesta revisão.
